# MUH KHABIR AKSAN — Portfolio

Portfolio website built with Next.js App Router, React, TypeScript, and Tailwind CSS 4.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run typecheck
npm run build
npm start
```

The site includes a home page, project listing and detail pages, and a contact page. The design uses a dark cyber-terminal theme. `hello@example.com` is a placeholder address; replace it with a real address before publishing. Contact form submissions are not sent to a server yet; the form explicitly reports this to visitors.
